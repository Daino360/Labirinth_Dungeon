# Labyrinth Dungeon

Our first University project developed during my Bachelor's degree in Computer Engineering (2016–2017).

> Note: The project may require specific system configurations and was originally
> developed for a different environment.

## 🎮 Project Overview
Labyrinth Dungeon is a dungeon-based game where the player navigates a maze,
interacts with the environment, and kills enemies

## 🛠️ Technologies
- C++
- SFML
- CMake
- Basic game loop and state management

## 📁 Project Structure
The project is organized into multiple modules handling game logic, entities,
and input management.

## 🚀 Build & Run
The project uses CMake for building.

```bash
mkdir build
cd build
cmake ..
make
````

## 🧠 What I Learned

* Structuring a medium-sized C++ project
* Applying object-oriented design principles
* Working with build systems (CMake)
* Debugging and maintaining legacy code
* Google testing and unit testing
* Usage of GitHub

## 📌 Project Status

This project is preserved for documentation purposes.
Some parts may not compile or run correctly on modern systems.
